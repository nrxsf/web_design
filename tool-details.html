How the Type Inference Engine Works

Deterministic AST traversal built on WebAssembly for near-zero memory allocation and exact recursive type synthesis.

  1. 1 Native WASM

    Deterministic AST Parsing

    Reads the raw byte stream client-side to generate a concrete syntax tree without server round-trips or serializing overhead.

  2. 2 PascalCase

    Recursive Structure Ingestion

    Traverses nested object trees and dictionary properties, generating hoisted, reusable interface declarations for all sub-entities.

  3. 3 Strict Union

    Union & Array Resolution

    Analyzes heterogeneous array members, dynamically unifying divergent primitive or object schemas into precise union bounds ((string | number)[]). 

import { jsonToTypeScript } from '@devforge/type-engine';

const rawPayload = { "project": "devforge", "active": true, "stars": 4920 };

const { dtsOutput, summary } = await jsonToTypeScript(rawPayload, {
  rootName: 'ProjectManifest',
  exportInterfaces: true,
  makeOptional: false,
  declarationStyle: 'interface' // or 'type-alias'
});

console.log(dtsOutput);
// => export interface ProjectManifest { ... }
