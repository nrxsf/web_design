How to Contribute

Submit a new self-contained micro-utility in under 15 minutes. No complex boilerplate or cloud keys required.

Read Tool Definition Spec →
  1. 1 INITIALIZE

    Fork & Clone

    Clone the repository and install lightweight dependencies with pnpm. Pure deterministic tooling with zero cloud secrets.

    git clone https://github.com/devforge/tools.git
  2. 2 IMPLEMENT

    Author Micro-Utility

    Define your utility in src/tools/ implementing the strictly-typed ToolDefinition interface using pure functions.

    export const defineTool = ({ id, run }) => ({ ... })
  3. 3 INTEGRATE

    Submit Pull Request

    Automated CI guarantees strict type safety, zero memory leaks, and passes bundle payload thresholds (<5kb net delta).
